# Day 43 — App Project: Planning
**Phase 3 · Week 7 · Monday**

---

## Goals
- Define what you're building clearly enough to explain it in 2 minutes
- Plan your data model and screens before touching any code
- Scaffold the project cleanly

---

## Tasks
1. Choose your app — pick something genuinely useful. Ideas: movie tracker (OMDb API), budget tracker, local news reader, task manager with categories and priorities
2. Write a `PLAN.md`:
   - What does the app do? (2–3 sentences)
   - Who is it for?
   - What are the 5 core features? (no more than 5)
   - What screens does it need? (sketch each one)
   - What's the data model? (entities, fields, relationships)
   - What external API, if any?
3. Set up the project: Hilt, Room, Navigation, Retrofit if needed, Material 3
4. Create the nav graph with all screens as empty destinations
5. First commit — push the scaffold

---

## Challenge
Write your Room entities and DAO interfaces before writing any UI. Getting the data model right first prevents painful refactors. Do any of your entities have relationships? Do you need a junction table?
