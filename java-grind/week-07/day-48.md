# Day 48 — App Project: Testing & Final Push
**Phase 3 · Week 7 · Saturday**

---

## Goals
- Write meaningful tests for your ViewModel
- Produce a clean, well-documented GitHub repo you'd show to someone

---

## Tasks
1. Write unit tests for at least one ViewModel: loading state updates correctly, data transforms correctly
2. Write at least 2 Espresso instrumented tests simulating real user interactions
3. Fix any bugs surfaced during testing
4. Write a complete `README.md`: what the app does, screenshots, architecture overview, how to build and run, which API is used
5. Tag the release as `v1.0` and push

---

## Challenge
Record a short screen recording of your app in use (Android Studio emulator has a built-in recorder). Add the GIF or video to your README. A working demo makes the repo dramatically more impressive at a glance.
