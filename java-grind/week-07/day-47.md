# Day 47 — App Project: Detail Screen & Polish
**Phase 3 · Week 7 · Friday**

---

## Goals
- Build the detail screen with proper data passing via Safe Args
- Polish the app to the point where you'd actually use it

---

## Tasks
1. Build the detail screen — show all information about a selected item
2. Add edit functionality: user modifies and saves from the detail screen
3. Add delete from detail screen, then navigate back to list
4. Polish the list: empty state, loading indicator, smooth screen transitions
5. Test every user flow end-to-end: add, view, edit, delete, search, rotate — fix every crash

---

## Challenge
Add shared element transitions between the list item and detail screen — a visual animation where a specific element smoothly becomes its larger version on the detail screen. It's a polish touch, but the kind that makes an app feel real.
