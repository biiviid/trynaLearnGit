# Day 29 — Android Studio Setup & Hello Android
**Phase 3 · Week 5 · Monday**

---

## Goals
- Get Android Studio running and understand what makes it different from a plain Java project
- Understand the anatomy of an Android project: what lives where and why
- Run your first app on an emulator

---

## Tasks
1. Install Android Studio — on Windows use your current setup; for Garuda Linux, get the Linux build from developer.android.com
2. Create a new **Empty Activity** project — select Java (not Kotlin)
3. Before running anything, explore: `AndroidManifest.xml`, `res/layout/`, your Java package, `build.gradle`
4. Run the default app on the emulator — watch the build process in the console
5. Change the text on screen by editing the XML. Then change it programmatically in `MainActivity.java`. Know the difference.

---

## Challenge
Find where the app's name is defined and change it. Find where the launcher icon lives. Change the main screen's background color using only XML — what file controls this and why?
