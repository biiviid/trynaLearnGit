# Day 30 — Views & XML Layouts
**Phase 3 · Week 5 · Tuesday**

---

## Goals
- Build UIs in XML and understand how XML relates to Java code
- Use `ConstraintLayout` to position views relative to each other
- Find and interact with views from Java using `findViewById`

---

## Tasks
1. Build a "Name Card" layout: image placeholder (colored View for now), large name TextView, smaller subtitle, row of buttons at bottom
2. Add a Button that changes the name text programmatically on click
3. Add an `EditText` where users type a new name and a button that applies it
4. Try `LinearLayout` for a simple vertical stack — compare the experience to `ConstraintLayout`

---

## Challenge
Create a form layout: name, email, phone fields and a submit button. On submit, validate that no field is empty and that email contains "@". Show feedback on screen based on validation result.
