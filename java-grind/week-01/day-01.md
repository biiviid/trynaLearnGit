# Day 01 — Setup & Hello World
**Phase 1 · Week 1 · Monday**

---

## Goals
- Get your Java environment running and understand what you're actually running
- Understand the difference between JDK, JRE, and JVM — not just the acronyms, but *why* they're separate things
- Write and run your first Java program from scratch

---

## Tasks
1. Install JDK 21 and IntelliJ IDEA Community if you haven't yet
2. Create a new Java project in IntelliJ — explore what folders get generated and ask yourself what each one is for
3. Write a `HelloWorld.java` file manually — don't use the template
4. Run it. Then try to run it from your terminal using `javac` and `java` commands directly
5. Break something intentionally — remove a semicolon, misspell `main`, see what the errors actually say

---

## Challenge
Write a program that prints your name, your course, and today's date — each on a separate line, using only one `System.out.println` call. Think about what character lets you do that.
