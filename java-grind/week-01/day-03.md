# Day 03 — Operators & Conditionals
**Phase 1 · Week 1 · Wednesday**

---

## Goals    
- Use all comparison and logical operators confidently (`==`, `!=`, `&&`, `||`, `!`)
- Understand when to use `if/else if/else` vs `switch`
- Know what the ternary operator is and when it makes code cleaner vs messier

---

## Tasks
1. Build a grade calculator: take a numeric score and print the letter grade — use `if/else if` first, then rewrite with `switch`
2. Write a program that checks if a number is positive/negative/zero AND even/odd — combine both checks into one readable output line
3. Rewrite one of your `if/else` conditions as a ternary — does it read better or worse?

---

## Challenge
A movie ticket costs a base price of ₱180. Rules:
- Children (under 12): 25% off
- Seniors (60+): 30% off
- Students (with ID): 20% off
- Regular: no discount
- On Tuesdays: extra ₱20 off for everyone

Write the logic. Think about the order of your conditions — does order matter here?
