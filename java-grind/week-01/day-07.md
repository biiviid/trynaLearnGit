# Day 07 — Review + Mini Project: Student Grade Manager
**Phase 1 · Week 1 · Sunday**

---

## Goals
- Apply everything from Week 1 in one cohesive program
- Practice thinking about structure before writing code
- Solidify your Git commit workflow

---

## Tasks
1. Before any code — write out what the program needs to do and what data it holds (paper or comment block)
2. Build the Student Grade Manager:
   - Add a student (name + numeric grade)
   - Remove a student by name
   - List all students
   - Calculate and display the class average
   - Find the highest and lowest grade
3. Use `ArrayList` for storage, loops for all operations, conditionals for edge cases (empty list, student not found)
4. Commit your work with a clear message and push to GitHub

---

## Challenge
Add a threshold feature: given a grade the user specifies, list all students *below* that threshold. Then sort the full list by grade descending — implement the sort yourself, no `Collections.sort()`.
