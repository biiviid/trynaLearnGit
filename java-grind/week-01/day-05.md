# Day 05 — Arrays & ArrayLists
**Phase 1 · Week 1 · Friday**

---

## Goals
- Understand the fundamental difference between arrays (fixed) and ArrayLists (dynamic)
- Perform CRUD on both and notice which one resists you less
- Loop through both using regular `for`, indexed, and enhanced `for-each`

---

## Tasks
1. Create an array of 5 student names. Print them. Try to add a 6th — what happens?
2. Do the same with `ArrayList<String>`. Add, remove, and update entries freely
3. Write a method that takes `int[]` and returns the largest value — no built-in sort or max allowed
4. Convert your array to an ArrayList and back — look up how, then think about why you'd ever need to

---

## Challenge
You have an `ArrayList` of integers. Without using any sorting libraries:
- Remove all duplicates
- Print the remaining values in reverse order
- Print the sum of remaining values

Think through the duplicate detection logic yourself before coding it.
