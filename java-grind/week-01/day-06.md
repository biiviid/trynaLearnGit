# Day 06 — Git Fundamentals
**Phase 1 · Week 1 · Saturday**

---

## Goals
- Understand Git as a tool for tracking *changes*, not just saving files
- Know the three states of a file in Git: modified, staged, committed
- Have your Week 1 work living on GitHub

---

## Tasks
1. Install Git if needed, configure your global username and email
2. Initialize a Git repo inside your Java project folder
3. Make your first commit — just the project structure is fine
4. Make 3 more commits after meaningful changes — write messages that describe *what changed and why*, not just "update"
5. Create a GitHub repo and push everything up
6. Examine `git log` — understand every line you're reading

---

## Challenge
Edit a file, stage it, then unstage it without losing the changes. Then try to stage only *part* of the file using `git add -p`. Understand what just happened before moving on.
