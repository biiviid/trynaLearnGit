# Day 12 — Git Branching & Merging
**Phase 1 · Week 2 · Friday**

---

## Goals
- Understand branches as parallel lines of work, not backup copies
- Create, switch, and merge branches confidently
- Know what a merge conflict looks like and how to resolve one calmly

---

## Tasks
1. In your banking project repo, create `feature/credit-account`
2. Add `CreditAccount` on that branch with at least 2 commits
3. Switch back to `main` — notice the file isn't there
4. Merge your feature branch into `main`
5. Deliberately create a conflict: edit the same line in `BankAccount.java` on both `main` and a new branch, then merge and resolve manually

---

## Challenge
Look up `git rebase` — understand what it does differently from `git merge`. You don't need to use it today, but know when you'd choose one over the other. Write a 3-sentence summary in your notes.
