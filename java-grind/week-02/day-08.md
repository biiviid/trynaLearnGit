# Day 08 — OOP: Classes & Objects
**Phase 1 · Week 2 · Monday**

---

## Goals
- Understand *why* OOP exists — what problem it solves over procedural code
- Define a class with fields, a constructor, and methods
- Create multiple instances and see that each holds its own independent state

---

## Tasks
1. Create a `BankAccount` class: owner name, account number, balance as fields
2. Write a constructor that sets all three at creation time
3. Add `deposit(double amount)` and `withdraw(double amount)` methods
4. In `main()`, create 3 different accounts, perform operations on each — confirm they don't interfere
5. Write a `toString()` method yourself and use it to print each account's summary

---

## Challenge
What happens if someone deposits a negative amount? Or withdraws more than the balance? Add guards for both — but think first: should the method return something? Throw something? Print something? Make a deliberate decision and justify it in a comment.
