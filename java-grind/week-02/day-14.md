# Day 14 — Review + Mini Project: Library System
**Phase 1 · Week 2 · Sunday**

---

## Goals
- Build a complete OOP system using everything from Week 2
- Practice the Git feature-branch workflow on a real project
- Think about design before writing — what classes? What are their responsibilities?

---

## Tasks
1. Design first: classes, fields, relationships — on paper before any code
2. Build the Library System:
   - `Book`: title, author, ISBN, available (boolean)
   - `Library`: holds the collection
   - Methods: add book, remove by ISBN, search by title or author, borrow, return
3. Handle edge cases: borrowing an already-borrowed book, ISBN not found
4. Use a feature branch for at least one addition — merge it into main when done
5. Push to GitHub with a `README.md`

---

## Challenge
Add a `Member` class that can hold up to 3 borrowed books at a time. A 4th borrow attempt throws a custom exception. Each member should track their borrowing history.
