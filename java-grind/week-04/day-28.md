# Day 28 — Phase Capstone: Contact Book
**Phase 2 · Week 4 · Sunday**

---

## Goals
- Build your most complete Java project yet — everything from Phase 1 and 2 in one app
- Show that you can *design* a system, not just write code

---

## Tasks
Build a **Contact Book CLI application**:
- `Contact` class: name, phone, email, list of tags/labels
- `ContactBook` class: `HashMap` storage — think about what the right key is
- Full CRUD: add, remove, update, find by name, find by tag
- Stream-based search: filter by tag, sort by name
- Gson JSON persistence: load on startup, save on exit and every write
- At least 5 JUnit tests covering core behavior
- Full Git history with feature branches for at least 2 features
- A `README.md` that explains what it does and how to run it

---

## Challenge
Add import/export: export contacts to CSV, import from CSV (merging into existing contacts, not replacing). Handle duplicate detection on import.

---

## Resources
- Design the architecture before writing any code. What classes? What does each one own?

---

> You've finished Phase 2. You now know enough Java to build real things. What would you build if you had to make something genuinely useful for someone you know?
