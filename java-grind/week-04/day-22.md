# Day 22 — Lambda Expressions
**Phase 2 · Week 4 · Monday**

---

## Goals
- Understand lambdas as shorthand for anonymous classes implementing functional interfaces
- Write lambdas in different forms: single expression, block body, method reference
- Stop seeing them as magic — recognize the pattern

---

## Tasks
1. Write a `Runnable` as an anonymous class, then rewrite it as a lambda — see the direct equivalence
2. Rewrite all your `Comparator` implementations from Day 19 as lambdas
3. Use method references (`::`) where possible: `String::toLowerCase`, `System.out::println`
4. Look up `Function<T,R>`, `Predicate<T>`, `Consumer<T>`, `Supplier<T>` — write one example of each

---

## Challenge
You have a list of strings. Using only lambdas and method references (no loops, no if statements), filter out strings shorter than 4 chars, convert the rest to uppercase, and print each one. Do it in 3 lines or fewer.
