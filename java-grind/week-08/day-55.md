**Phase 4 · Week 8 · Saturday**

## Goals
- Present your work professionally on GitHub
- Write documentation that makes your projects understandable to a stranger

---

## Tasks
For **both repos** (Android app + Spring Boot API):
1. Write a complete `README.md`:
   - What it does (2–3 sentences)
   - Tech stack
   - Architecture overview
   - Screenshots (Android) or endpoint table (Spring Boot)
   - How to build and run locally
2. Clean up your commit history — no "asdf" or "fix" messages at the top
3. Tag both as `v1.0`
4. Add `ARCHITECTURE.md` documenting your design decisions

---

## Challenge
Add Swagger UI to Spring Boot using SpringDoc OpenAPI. Visit `http://localhost:8080/swagger-ui.html` — you should see an interactive API explorer. This is standard in professional Java backends.
