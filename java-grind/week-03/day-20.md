# Day 20 — Git: Pull Requests & GitHub Flow
**Phase 2 · Week 3 · Saturday**

---

## Goals
- Understand Pull Requests as a *review mechanism*, not just a merge button
- Know the GitHub Flow: branch → commit → PR → review → merge
- Get comfortable forking and contributing to someone else's repo

---

## Tasks
1. On your Library System repo, create a feature branch for adding the `Member` class
2. Push it to GitHub and open a Pull Request — write a real PR description: what changed and why
3. Fork any beginner Java repo on GitHub, make a small improvement, open a PR
4. Study your own PR in the "Files changed" tab — review it as if you were someone else

---

## Challenge
Look up GitHub Actions — just enough to understand what CI/CD means. Find a simple Java build workflow online (`.github/workflows/`), add it to your repo, and watch it run. Debug it if it fails.
