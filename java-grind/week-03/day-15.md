# Day 15 — Collections Framework Overview
**Phase 2 · Week 3 · Monday**

---

## Goals
- See the Collections Framework as a family of tools — each built for a specific job
- Know when to reach for `List`, `Set`, or `Map` without hesitating
- Understand the key tradeoffs at a high level: lookup speed, ordering, duplicates

---

## Tasks
1. Create a `HashMap<String, String>` phone book: name → number
2. Practice `put`, `get`, `remove`, `containsKey`, `containsValue`
3. Iterate over the map three ways: `keySet()`, `values()`, `entrySet()`
4. Try putting a duplicate key — what happens and why?
5. Create a `HashSet<String>` and try adding duplicates — observe the behavior

---

## Challenge
You have a list of student names with duplicates. Using only Collections classes (no manual loops for deduplication), produce a sorted list of unique names. Think about which collection types naturally solve each part of the problem.
