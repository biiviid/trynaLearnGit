# Day 16 — HashMap & HashSet Deep Dive
**Phase 2 · Week 3 · Tuesday**

---

## Goals
- Use HashMap and HashSet to solve real problems efficiently
- Understand *why* these are O(1) lookup at a conceptual level — what actually is a hash?
- Know how `null` keys and values behave in a HashMap

---

## Tasks
1. Count the frequency of each word in a sentence using `HashMap<String, Integer>`
2. Find all duplicate values in an integer array using `HashSet` — no nested loops allowed
3. Use `getOrDefault()` and `putIfAbsent()` — understand what problem each one solves
4. Look up `LinkedHashMap` and `TreeMap` — how do they differ from `HashMap`? When would you reach for each?

---

## Challenge
You have two ArrayLists of strings. Find the intersection (words in both lists) without nested loops. Then find the union. Then find words in List A but not List B. Which Set operation maps to each task?
